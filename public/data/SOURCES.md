# Fuentes de datos

## strongs-hebrew.json

Generado a partir de `HebrewStrong.xml` del proyecto Open Scriptures Hebrew Bible
(https://github.com/openscriptures/HebrewLexicon), licencia Creative Commons
Attribution 4.0 International (CC BY 4.0). El texto del diccionario de Strong
en sí es de dominio público; la atribución es al Open Scriptures Hebrew Bible
Project por la compilación y correcciones.

## strongs-greek.json

Generado a partir de `strongsgreek.xml` del proyecto de Ulrik Sandborg-Petersen
(https://github.com/morphgnt/strongs-dictionary-xml), liberado bajo CC0
(dominio público).

Ambos archivos contienen solo un subconjunto de campos (palabra original,
transliteración, número de Strong, significado) extraídos de los XML
originales para uso de autocompletado en el editor de anotaciones.
